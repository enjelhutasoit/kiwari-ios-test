  <strong>HAY<br>(How Are You)</strong>
</p>

HAY is a simple iOS instant messaging application based on Firebase created by 
<a href="https://github.io/enjelhutasoit">@enjelhutasoit</a>. <br>
Goal of this project is to provide a very simple and easy way for our beloved grandma/grandpa to
essentially see and sent messages to another user in chatroom.

## FEATURES
List of features ready: 
- [x] Login page: user can input email & password, then click login button
- [x] Chatroom page: user can see message avatar and name opponent user on toolbar
- [x] Chatroom page: user can see message list item (content & date sent)
- [x] Chatroom page: user can input text & send it with sent button 
- [x] Log out button: user can logout and show Login Page
